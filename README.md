# DO NOT LET IT FINISH LOOKING

An interactive, single-page archival horror experience built around a distorted monochrome photograph. The evidence reacts to attention: holding focus clarifies it, calibration brings it closer, and attempting to close the file completes the recovery.

## Experience

- Pointer-reactive evidence viewer
- Press-and-hold focus mechanic
- Scroll-driven interview transcript
- Deceptive calibration controls
- Generative browser audio using the Web Audio API
- Interactive destruction timeline
- Responsive design, keyboard support, and reduced-motion handling
- No trackers, cookies, frameworks, or external audio files

## Run locally

Open `index.html` directly, or serve the directory with any static web server.

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content note

This is a fictional work of psychological horror. The pictured subject is presented solely as fictional archival evidence; the story makes no real-world claims about any person.
